# cyber-complaint-analyzer
AI-based platform to analyze cybercrime complaints. It classifies cases (phishing, UPI fraud, job scams, etc.) and extracts key data like phone numbers, emails, URLs, and UPI IDs. Designed to reduce manual workload and support faster, data-driven investigation.

## 🚔 Cyber Complaint Analysis System
An AI-assisted web app that analyzes cybercrime complaints. It classifies cases (phishing, UPI fraud, job scams, etc.) and extracts key entities like phone numbers, emails, URLs, and UPI IDs to support faster investigation.

## ⚙️ Features
* Complaint classification
* Entity extraction (phone, email, URL, UPI)
* Simple and interactive interface
